# СтройКонтроль ИД — MVP

Автономная предварительная версия веб-приложения для контроля подготовки исполнительной документации.

## Запуск

Откройте [index.html](index.html) в современном браузере.

Приложение не требует установки зависимостей или сервера. Тестовые данные, созданные работы и изменения статусов хранятся в `localStorage` браузера.

Для следующего этапа в [supabase/schema.sql](supabase/schema.sql) подготовлена схема PostgreSQL/Supabase со всеми ключевыми сущностями, версиями документов и журналом аудита.

## Что реализовано

- русскоязычный адаптивный интерфейс с боковым меню;
- панель руководителя с показателями, диаграммами и критическими ситуациями;
- реестр из 12 тестовых выполненных работ и фильтры;
- форма создания работы с автоматическим созданием четырёх задач;
- канбан и табличное представление задач, смена статусов и журнал изменений;
- реестры исполнительной, геодезической, лабораторной документации и документов качества;
- демонстрационная загрузка файлов и предзаполнение ИИ;
- реестр, предварительная форма АОСР, проверка комплектности и скачивание демонстрационного акта;
- отчёты, справочники, матрица ИД и переключение роли пользователя;
- ролевой доступ к созданию работ, загрузке документов и формированию АОСР;
- расширенная фильтрация реестра работ по сооружению, участку, виду работ, производителю, периоду, готовности, АОСР и просрочке;
- фильтрация отчётов по сооружению и экспорт отчёта в CSV.
- экспорт, импорт и подтверждаемый сброс локальных данных MVP.
- личный кабинет для каждой роли: профиль, персональная нагрузка, доступные действия и настройки уведомлений.
- печатная A4-форма АОСР по структуре приложения № 3 к приказу Минстроя России № 344/пр с возможностью сохранения в PDF через диалог печати браузера.

## Локальный защищённый запуск

Для работы с локальной базой данных, входом по API и файлами запускайте сервер, а не открывайте `index.html` напрямую:

```powershell
& 'C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' server.py
```

После запуска откройте `http://127.0.0.1:8797`. Данные хранятся только на этом компьютере: база — `data/portal.sqlite3`, файлы — `data/files/`. Папку `data` необходимо включать в резервное копирование.

Сервер создаёт учётные записи сотрудников при первом запуске. Учётная запись администратора: `admin@stroi.local` / `Admin2026!`. API уже предусматривает типы учётных записей `employee` и `contractor`; подрядчиков добавляет администратор.

ЭЦП в локальной версии не применяется. При переходе на сервер потребуется заменить локальное файловое хранилище и SQLite на корпоративные сервисы, а также перенести секреты и сессии в защищённую среду.
